# LAT-CES Constitutional Documentation

Kanonski redoslijed ustavne dokumentacije:

1. `LAT-CES-0000` — zašto LAT-CES postoji i koji su nepromjenjivi principi.
2. `LAT-SCOPE-0001 Rev B` — šta sistem obuhvata i kako su domene organizovane.
3. `LAT-CES-0001` — kako se ustavni okvir preslikava na tehničku arhitekturu.

Implementacija mora ostati kompatibilna sa sva tri dokumenta.
