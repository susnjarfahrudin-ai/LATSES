# SMC-002 — Legacy 0001–0055 Consolidation

Decision vocabulary: KEEP / MERGE / ADAPT / MOVE / RETIRE / NEW.

KEEP: canonical implementation already satisfies the target contract.
MERGE: multiple implementations represent the same scientific responsibility.
ADAPT: implementation exists but must conform to canonical Scientific Core contracts.
MOVE: implementation belongs in a different canonical layer/path.
RETIRE: superseded implementation after migration proof.
NEW: no accepted implementation exists; create only from SCI requirements and tests.

No RETIRE action is permitted before import/regression/traceability checks pass.
